# Changelog

## 0.2.0

- Add `--json` for the cache, gc, and safe-to-delete reports.
- Add `--min-size` to hide small caches and clones.
- Add a release workflow for PyPI trusted publishing.
- Add tests for JSON output and size parsing.

## 0.1.0

- Initial Python port of the bash `git-reclaim` tool.
- Cache report and purge, `git gc`, and safe-to-delete listing.
- Keep tagged repos, tracked directories, and repo boundaries safe.
